Leonida Trophy Guide — an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: official names, descriptions and grades, a guide in our own words with a cited source beside every trophy, a roadmap to the platinum, missable flags, and a checklist that saves in the browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the guide runs fully offline, no network requests. To hand in the entry exactly as the grader does:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
